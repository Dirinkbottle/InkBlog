# 博客阅读体验升级

前台仍使用 React / Vite，后端仍使用 Gin / GORM，无需迁移数据库或更换部署方式。

## 页面与使用方式

- `/`：常驻首页，显示后台配置的站名、介绍、统计、最新文章、分类与标签。移除三秒自动跳转。
- `/posts` 和 `/search`：关键词、分类和标签组合筛选；最新、最早、最多阅读排序；分页、卡片/列表视图。筛选保存在 URL，支持刷新、分享和浏览器前进后退。搜索按回车或点击「搜索」提交。
- `/archives`：按年份筛选，按月份展示已发布文章，每页最多 30 篇；日期按 UTC 分组。
- `/library`：稍后读和阅读足迹。当前浏览器本地保存，最多 200 篇收藏、50 条足迹，支持跨标签页同步，不跨设备同步；不会保存正文、令牌或作者私人信息。被删除的文章卡片可能保留，打开时会显示不可用状态。
- `/posts/:id`：自动目录、阅读进度、继续阅读、字号记忆、专注模式、复制链接与代码、键盘可操作的图片预览、相关文章。未注册的代码语言按纯文本展示。
- 导航：`Ctrl/Cmd + K` 打开搜索；手机菜单支持 Escape；提供跳到正文入口和减少动画偏好支持。
- 后台「网站设置 → 基本设置」：编辑博客名称、首页标题/简介、侧栏寄语和公开地址。清空首页标题使用默认标题，清空首页简介使用网站描述。保存后刷新前台设置缓存。

## API

现有 `GET /api/v1/posts` 新增：

| 参数 | 可用值 | 行为 |
| --- | --- | --- |
| `sort` | `newest`, `oldest`, `popular` | 发布时间正倒序或浏览量倒序；以 ID 保证稳定顺序 |
| `year` | 1970–9998 | 按发布时间（缺失则创建时间）筛选 |
| `month` | 1–12，配合 `year` | 使用左闭右开的日期区间 |

不传 `sort` 保留后台原有的创建时间倒序。公开接口始终限制为 `published`，忽略客户端的 `status`；认证管理接口继续支持草稿。

`GET /api/v1/archives` 返回 `{data: {months: [{year, month, count}], total}}`。数据库聚合仅统计未删除的已发布文章，不加载正文。

`GET /api/v1/feed.xml` 返回最新 50 篇已发布文章的 RSS 2.0 摘要。标题、摘要和标签安全编码。文章绝对链接优先使用后台的 `site_url`，留空使用请求地址；反向代理应正确传递 Host 和 X-Forwarded-Proto。订阅入口在页脚和侧栏，HTML 头部提供自动发现链接。

公开 `/settings` 只返回明确列出的展示/评论/注册开关。SMTP 用户名、密码和服务配置保留在认证管理接口。Markdown 保留常见排版、表格和代码，移除脚本、事件属性及 iframe 等可执行内容。

## 验证

```sh
cd backend
go test ./...

cd ../frontend/blog
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

如需使用系统 Chromium，可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`。

后端回归使用 SQL mock 验证公开/管理员权限差异、归档查询、日期边界、排序白名单和 RSS 编码，不连接生产数据库。浏览器回归使用 `tests/e2e/fixtures.js` 中的确定性数据；示例文章不会进入生产代码或数据库。新增的 GitHub Actions 在 PR 中执行 Go 测试、前端单测、构建及 Chromium 回归。

发布时需同时更新前后端，因为归档、排序和 RSS 依赖新增 API。现有部署流水线未改变。后台编辑器依赖仍然较大，但已按路由加载，不再阻塞首页；本文未声称静态 HTML 已具备服务端 SEO 渲染。
